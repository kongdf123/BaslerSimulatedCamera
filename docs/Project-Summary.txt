完整总结
根因
KWinSprint 的相机发现链是硬编码的 Basler Pylon SDK 调用：

text



VideoSettings.Search → BaslerDeviceEnumerator.TryEnumerateDevices()
  → Pylon.CameraFinder.EnumerateDevices()
    → 只返回 Pylon SDK 能看到的真实 Basler 相机
我们的 TCP 模拟器（127.0.0.1:5270）不在这个链路上，所以无论怎么运行都不可能被发现。

零修改方案 —— Pylon 官方相机仿真
在追踪 KWinSprint 源码时发现了已内置但未启用的 PYLON_CAMEMU 机制：

位置	说明
BaslerPylonEnvironment.cs:14	PYLON_CAMEMU=N 环境变量是 Basler 官方仿真开关
BaslerPylonEnvironment.cs:42-46	已存在值时尊重不覆盖（KWinSprint 调用传 0 但尊重外部值）
App.xaml.cs:114	启动时调用 TryConfigureCameraEmulation(0)
BaslerDeviceEnumerator.cs:469	每次枚举前调用 TryConfigureCameraEmulation(0)
工作原理：Basler Pylon SDK 首次初始化时读取 PYLON_CAMEMU=N，自动创建 N 台虚拟 Basler 相机 —— 它们完全兼容标准 Pylon API，通过 CameraFinder.EnumerateDevices() 正常返回。
